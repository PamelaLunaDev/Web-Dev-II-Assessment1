
# My Dream Destination

## Project Description

My Dream Destination is a responsive, single-page website about Paris, France.

The website presents information about Paris, popular places to visit, and a photo gallery showing different views of the city.

The project was created as part of the Web Development II Formative Assessment 1, Web Refresher.

## Technologies Used

- **HTML5:** To create the structure and content of the website.
- **CSS:** To style the website and create a responsive layout using CSS Grid, Flexbox and media queries.
- **JavaScript:** To add interactivity, allowing users to show and hide information about Paris.

## Project Features

- Navigation menu linking to different sections.
- Information about Paris and places to visit.
- Photo gallery with four images.
- Interactive button to show and hide a fact about Paris.
- Responsive layout for desktop and mobile devices.
- Semantic HTML elements and alternative text for images.

## How to Run the Website

1. Download or open the project folder.
2. Locate the `index.html` file.
3. Open `index.html` in a web browser.
4. Use the navigation menu to explore the website.
5. Click the "Show Paris Fact" button to test the JavaScript interaction.
